Privacy Policy

Last updated: July 23, 2026

Ascent respects your privacy. This page describes what we collect and how we use it.

What we collect

  • Account and app usage data needed to provide core app features.
  • Optional analytics and crash diagnostics to improve reliability.
  • If enabled, iOS Screen Time-related inputs used for personalized habit features.

How we use data

  • To provide app functionality (goals, plans, reminders, and task guidance).
  • To improve performance, quality, and user experience.
  • To communicate important product updates.

Ascent ChatGPT app

The first version of the Ascent ChatGPT app is anonymous and read-only. When a connected user invokes an Ascent tool, the Ascent MCP endpoint receives the arguments for that selected tool. It does not receive the rest of your ChatGPT conversation.

  • The planning tools compute a result in memory and the website does not store generated plans on the website server.
  • The review tool analyzes only the snapshot supplied to that tool. It does not automatically access your Ascent account, iPhone, Screen Time history, health data, contacts, or calendar.
  • The focus tool prepares a handoff. It does not start a focus session or change device restrictions inside ChatGPT.
  • No ChatGPT-app tool in this version requires an Ascent account, OAuth token, or advertising identifier.

Plan handoff links

A generated handoff carries plan details in the URL fragment, which is the part after the #. Browsers do not include a URL fragment in the ordinary request sent to the website server. The handoff page decodes the plan in the browser and does not use analytics, cookies, local storage, session storage, or a server database.

Anyone who receives the complete handoff link may be able to read the plan in it. Treat the link like the plan itself and avoid putting sensitive personal, medical, financial, or account information into a handoff.

Sharing

We do not sell personal data. We only share data with service providers needed to operate Ascent (for example hosting, analytics, and payments), subject to contractual safeguards.
